Agentic AI Workshop — Afternoon Plans

Two parallel hands-on tracks following Sean Davis's morning lectures (intro to agents; skills, MCP, and sub-agents). Attendees self-select at lunch with one question: "Have you ever let an AI agent run code or edit files for you?" No fixed clock — each track flows at the room's pace, with a joint break midway.

Instructor
Sean Davis + 3–4 Vahedi lab TAs
Audience
Epigenetics Institute faculty & trainees
Format
Two tracks, self-paced, joint break
Materials repo (live, public): github.com/golnazvahedi/epigenetics-agentic-workshop
Every exercise and challenge ships with its own sample — two real Vahedi lab bulk datasets shared for teaching (workshop use only, per track-a/data/README.md), a simulated sample sheet, a bundled open-access paper, and a verified public data target — so nobody needs their own data. Attendees just git clone.

Before the workshop (both tracks)

The single biggest predictor of whether the afternoon works. Email one week ahead, remind two days ahead:

  • Get a coding agent working before you arrive — mirrors Sean's Harvard prerequisite. Recommended: Claude Code (desktop app is the gentlest on-ramp). Fallbacks: Gemini CLI, Copilot agent mode, Codex. Attendees confirm they can open the tool and get a response.
  • Laptop + charger, working terminal. Track B: also git, and ideally one of their own projects cloned.
  • Setup clinic during lunch — two TAs run a help desk for failed installs.
  • TA prep (one afternoon): test every exercise in the repo end to end once.
Privacy ground rule, stated up front: no PHI, no personal unpublished data, no grant drafts anyone isn't comfortable sending to a model API. Every exercise has staged materials — including two real Vahedi lab datasets shared for teaching (workshop use only, don't redistribute) — so nobody needs their own data.

What's staged in the repo

  • Real DESeq2 H3K27ac ChIP-seq peak table (TCF-1 knockout vs empty-vector control, DN3 thymocytes; 49,781 union peaks) — the guided exercise. Its real pipeline quirks are the teaching material: chromosome names without a chr prefix, p-values of exactly 0 (what does −log10 do?), a 93-kb "peak", no gene annotation, and nothing stating which way the fold change points.
  • Real B-cell RNA-seq (CTCF-binding-site knockout vs wild type, mouse spleen): raw counts matrix + the lab's own DESeq2 table, with a genuine trap — a negative fold change means higher in the knockout, and padj is NA for most genes (independent filtering).
  • A deliberately messy simulated sample sheet (Card 2).
  • The open-access scBaseCount paper (Youngblut et al., Cell 2026, CC BY) for the paper-wrangling card — fitting, since the resource it describes was itself built by an AI agent.
  • A QC script with four planted bugs (one crash, three silent logic errors) — verified to fail on cue.
  • A pre-vetted figure-reproduction target: Calderon et al., Nat Genet 2019, GEO GSE118189, with a verified 111 MB processed counts file (no raw FASTQs needed).
  • A community/ folder where attendees PR their best prompts and CLAUDE.md files afterward.
Track A

"Getting Started" — new to agentic AI

Goal: every attendee personally directs an agent through real tasks — a paper, a messy table, a plot, a draft, broken code — and leaves with the verify-before-trust habit.

Staffing: 2 TAs embedded and roving — ratio matters more here than in Track B. Two parts, no clock:

  • Guided exercise — whole room together, projected.

    After a quick launch check (one throwaway prompt each; stragglers pair with a neighbor — pairing is a feature), a TA drives on screen while everyone follows:

    "Explore the differential peaks file, tell me what's in it, flag anything suspicious, then make a volcano plot and a ranked table of the top 20 differential peaks by adjusted p-value."

    Three teaching beats: (1) you describe the goal, not the steps; (2) watch the plan–act–check loop — the "aha" moment; (3) interrogate the output — this is a real DESeq2 table with real quirks (p-values of exactly 0, a 93-kb peak, no stated fold-change direction), so "how do I know this plot is right?" has a real answer. Bonus question for the room: "which group has more signal when log2FC is positive?" — the agent can't know from the file alone, and that's the point.

  • Exercise cards — self-paced, any order.

    TAs rove. Each card: one task, one bundled sample, one "success looks like" line, one stretch goal. Once someone has done a few, TAs nudge them to try the pattern on one real, safe task from their own work — scoped small.

The five exercise cards

Card 1Paper wrangler

Audience-specific summary + structured extraction, then spot-check for invented details.

sample: scBaseCount PDF (Cell 2026, CC BY, bundled)
Card 2Sample-sheet rescue

"Make this tidy, tell me what you changed." Everyday drudgery is the killer app; builds the change-log habit.

sample: messy sample sheet (simulated)
Card 3Plot without coding

PCA and heatmap by conversation on real B-cell RNA-seq; stretch goal compares against the lab's own DESeq2 table and its fold-change-direction trap.

sample: real counts matrix + DESeq2 table
Card 4Writing assistant

Methods paragraph with [PLACEHOLDER] discipline; figure legend from bullets. The file doesn't state the reference group — a truthful draft must leave it blank.

sample: real H3K27ac peaks table + provided bullets
Card 5Debug my script

One crash + three silent bugs, all to be found, explained, and sanity-checked.

sample: broken QC script

Close with a short share-out — volunteers show one thing that worked or failed instructively — and the take-home habits: start small; give files, not descriptions of files; always ask for verification; never paste what you can't afford to leak; the agent is a tireless junior colleague, not an oracle.

Track B

"Level Up" — some experience

Goal: every attendee leaves with a working artifact using at least one truly agentic capability from the morning — a CLAUDE.md/skill, an MCP connection, a sub-agent pattern, or an end-to-end reproduction — not just more chatting.

Staffing: 1–2 TAs; Sean floats here (this room asks the harder questions). Pods and demos, no clock:

  • Pick a challenge, form pods of 3–5.

    Four stations posted on the wall; TAs cap pod sizes. Each pod writes one sentence before starting: "By the demo, we will show ___."

  • Build.

    TAs rotate. At some point a TA interrupts the room for two minutes to show a power move worth stealing (plan mode before a big change; spawning parallel sub-agents). House rule: a small thing that runs beats a big thing that almost runs.

  • Demos.

    Each pod: what they built, one thing the agent nailed, one thing it got confidently wrong. Sean closes with where this is heading.

The four challenges (each with a ready sample; BYO project encouraged)

Pod 1 · Skills & CLAUDE.mdTeach the agent your lab

Build the context layer for a real repo (CLAUDE.md + one reusable skill) and measure the with-vs-without difference on the same task. One person's setup becomes the whole lab's leverage.

sample: the workshop repo itself
Pod 2 · MCPConnect to the outside world

Use an existing PubMed/GEO/UCSC MCP server, or have the agent write a minimal one around a keyless REST API (Ensembl, NCBI E-utilities, ENCODE). Benchmark: "tabulate human Treg ATAC-seq datasets on GEO since 2024," hand-checked.

sample: keyless endpoints + benchmark query
Pod 3 · Real analysisReproduce a published figure

Pre-vetted target: Calderon et al. 2019 (open access), GEO GSE118189 — reproduce the sample-level clustering of 175 immune ATAC samples from the processed counts alone. Sub-agents fit naturally.

sample: verified 111 MB counts file
Pod 4 · AutomationAutomate something recurring

Agent-written sanity tests for a script; a "paranoid postdoc" review sub-agent; or a preprint-scan digest. Run it twice and show it holds up.

sample: the planted-bug QC script

Cross-cutting logistics

  • TA assignment (4 TAs): 2 rove Track A; 1 covers Track B pods 1–2; 1 covers pods 3–4. With 3 TAs: 2 on A, 1 on B with Sean anchoring.
  • Joint break midway so the rooms cross-pollinate; optional joint closing with one Track A share and one Track B demo — beginners see the ceiling, veterans remember the on-ramp.
  • Contingencies: if Wi-Fi/API access dies, Track A pivots to projected live demo + prompt-writing on paper; Track B pods 1 and 4 work offline against the cloned repo (the bundled paper and all datasets are already local). If the split is lopsided, pull a TA from B to A and let Sean hold B alone.
  • Capture the exhaust: everyone drops their best prompt or CLAUDE.md into the repo's community/ folder — the workshop leaves the institute a starter kit, not just a memory.
  • Follow-up hook: announce office hours 2–3 weeks later, hosted by the Vahedi lab TAs — adoption dies without a second touch.
